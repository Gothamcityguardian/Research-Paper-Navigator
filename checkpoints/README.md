# Capstone checkpoint trail

These folders preserve the completed capstone solutions, worksheets, and
selected evidence produced during the course. They show how the final system
developed from a no-retrieval baseline into the production-oriented system in
`src/research_paper_navigator/`.

| Checkpoint | Focus |
| --- | --- |
| 1.1 | No-retrieval baseline and observed hallucination/citation failures |
| 2.1 | Page-level keyword retrieval over the research-paper corpus |
| 3.1 | Evaluation framework and representative test set |
| 4.1 | Query decomposition, fusion, graph expansion, and retrieval refinements |
| 5.1 | Agentic retrieval, evidence coverage, and multistep decisions |
| 6.1 | Security, model usage, token/cost, and reliability audit |
| 7.1 | Production safeguards, routing, semantic caching, and performance evidence |

The checkpoint scripts are historical course artifacts and may retain their
original course-folder assumptions. Use the package under `src/` to run the
final organized implementation.
